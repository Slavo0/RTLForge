# Участие в проекте

Если нашли ошибку, откройте issue и укажите версию Python, версию Windows,
действия для воспроизведения и ожидаемый результат. Для проблем с CSV по
возможности приложите небольшой искусственный пример вместо личного захвата.

Перед pull request запустите:

```powershell
.\.venv\Scripts\python.exe -m unittest -v tests.test_waveform tests.test_extensions
```

Если изменение влияет на большие захваты, также запустите
`.\.venv\Scripts\python.exe -m scripts.benchmark_waveform`. Новое поведение
добавляйте в `ila_viewer/`, сохраняя `ila_viewer/__main__.py` точкой запуска.
Сведения об устройстве проекта находятся в [документе об архитектуре](docs/ARCHITECTURE.md).

Отправляя вклад в проект, вы соглашаетесь распространять его на условиях
[Apache License 2.0](LICENSE), если явно не указали иное.
