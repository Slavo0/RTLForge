# ILA Waveform Reader

Локальное приложение на Python + PySide6 для просмотра CSV, экспортированных
из Vivado ILA Hardware Manager. Исходный CSV открывается только для чтения.

## Запуск

1. Установите 64-битный Python 3.10 или новее (проверено с Python 3.12).
2. Запустите `setup.bat`: он создаст `.venv` и установит зависимости из интернета.
3. Запустите `start.bat` и откройте CSV через **Ctrl+O**, перетащите файл в
   окно или на `start.bat`. Если рядом со скриптом лежит личный `waveform.csv`,
   он откроется автоматически; этот файл не включён в репозиторий.

«Открыть CSV» запоминает последнюю выбранную папку. Кнопка **«Обновить CSV»**
справа в верхней панели заново читает текущий файл с диска. Цвета и форматы
совпавших сигналов сохраняются; подсветки пересчитываются по новому CSV, если
сигналы из их условий ещё существуют. Открытие другого файла начинает новый вид.

Окружение `.venv` привязано к компьютеру и установленному Python. При переносе
копируйте исходники, `requirements.txt`, файлы запуска и CSV, затем выполняйте
`setup.bat`; готовую `.venv` переносить не нужно.

Запуск из PowerShell с выводом диагностических сообщений:

```powershell
.\.venv\Scripts\python.exe -m ila_viewer
.\.venv\Scripts\python.exe -m ila_viewer "D:\captures\capture.csv"
```

## Возможности

- Шины вида `[8:0]`, `[31:0]` отображаются целиком и раскрываются на биты стрелкой слева.
- Однобитные сигналы отображаются уровнями 0/1.
- Radix: Default, Binary, Hexadecimal, Octal, ASCII, Unsigned Decimal,
  Signed Decimal, Signed Magnitude, Real и Real Settings.
- Широкие шины более 64 бит и значения X/Z поддерживаются.
- Горизонтальная и вертикальная прокрутка, масштабирование относительно мыши.
- Имена сигналов остаются слева при прокрутке времени; границу столбцов можно двигать.
- Переходы к предыдущему и следующему изменению выбранного сигнала.
- Точный поиск значения шины вперёд и назад с переходом через край захвата.
- Курсоры A/B, разность в отсчётах, приближение диапазона между курсорами.
- Фильтр имён, переход к индексу отсчёта и к первому `TRIGGER=1`.
- Начальный размер окна учитывает доступную область экрана. На узком окне
  дополнительные кнопки панели доступны через её раскрывающее меню.
- Загрузка и поиск выполняются в фоне; операцию можно отменить.
- Сохранение видимой диаграммы в PNG через меню «Файл».
- Перетаскивание сигналов, группы и разделители; отдельные значки шин, битов,
  групп и параметров захвата.
- Три темы в «Настройки → Настройки… → Вид»: нейтральная тёмная, светлая и синяя.
  Signal Color предлагает 24 цвета;
  варианты с достаточным контрастом отмечены словом «подходит».
- Подсветка участков A…B или всего захвата по условию, проверяемому в заданной фазе периода;
  несколько групп можно редактировать, скрывать, перекрашивать и удалять.

### Общие настройки и колонки

Пункт **«Настройки → Настройки…»** открывает вкладку «Вид». В ней выбираются тема, **общий Radix**, полные имена
и заливка уровня 1. По умолчанию шины и однобитные сигналы используют общий
цвет и общую настройку заливки. Включите «Раздельный вид», чтобы настроить
цвет шины отдельно от однобитного сигнала. Заливку шин можно включить и при общем
цвете сигналов. Цвета хранятся отдельно
для тёмной, светлой и синей тем. Прежняя тема с синим фоном называется **«Синяя»**;
**«Тёмная»** использует нейтральные серые оттенки.

Общий Radix применяется ко всем сигналам и раскрытым битам, у которых
в контекстном меню оставлен **Default**. Radix по правой кнопке меняет формат
всех выделенных сигналов; при одиночном выделении — только этого сигнала.
Индивидуальные настройки имеют приоритет. Default возвращает наследование общего формата.
Общий пункт «Исходный формат CSV» использует исходный Radix каждого столбца.
Real и Real Settings задаются для выделения и зависят от ширины и
представления выбранных шин. IEEE 754 доступен, если все выбранные сигналы имеют
ширину 32/64 бита; число дробных бит ограничено шириной самой узкой шины.

При включённой заливке полупрозрачным цветом закрашивается область под уровнем 1
однобитного сигнала; уровень 0 не закрашивается. Это относится и к раскрытым
битам шины. При включённой заливке шин заполняются их сегменты. На отдалённом
виде плотные переключения по-прежнему показываются
полосой активности, независимо от этой настройки.

**Name** и **Value** — независимые колонки. Перетаскивайте границу Name/Value,
чтобы менять ширину имён, и границу Value/диаграмма, чтобы менять ширину значений.
Двойной щелчок по соответствующей границе подбирает ширину по текущим видимым
в дереве строкам; для Value учитываются значения в точке A. Value также
увеличивается примерно в 1,5 раза, когда отображаемое значение не помещается;
изменение размера окна само по себе ширины не меняет.
Фильтр имён расположен над Name, слева от поиска значения.

Общие настройки сохраняются автоматически в **`.viewer-settings.json`** рядом
с программой: тема, общий Radix, заливка, полные имена, обе ширины колонок,
цвета сигналов по темам, стили подсветки, режим пустой панели и общего выключателя,
последняя папка CSV,
размер окна и развёрнутое состояние. Изменения ширины сохраняются с небольшой
задержкой, остальные настройки — после OK или закрытия окна. Файл не содержит
сигналов, групп (включая группы подсветки), их индивидуальных цветов/Radix,
маркеров, масштаба, периода ILA clock или имени ранее открытого CSV.
При запуске применяется сохранённый
общий вид; правила открытия `waveform.csv`/файла из аргумента остаются прежними.
Повреждённый файл настроек не мешает запуску: используются значения по умолчанию.

### Дерево сигналов и меню

Перетащите **имя** сигнала вверх или вниз. Линия показывает место вставки:
верхняя половина строки — перед ней, нижняя — после неё. Чтобы поместить
сигнал в группу, отпустите мышь в центре строки группы: появится рамка.
У края области имён во время переноса работает автоматическая прокрутка.
Esc отменяет перенос. Шина переносится вместе с битами, группа — с содержимым.
Биты можно переставлять внутри своей шины; переносить их из физической шины нельзя.
При выделении нескольких строк перетаскивание за имя любой из них переносит
весь выбранный набор, сохраняя порядок. Перенос проверяется целиком: если одна
из строк несовместима с местом назначения, ни одна строка не перемещается.

Обычный щелчок в Name или Value выбирает строку. **Shift + щелчок** по другой
строке выделяет весь диапазон между ними, включая обе крайние строки;
**Ctrl + щелчок** добавляет или убирает отдельную строку. Курсоры A/B при этом
не меняются. На диаграмме обычный щелчок выбирает строку и перемещает A,
Ctrl + щелчок добавляет или убирает строку из выделения и перемещает A.
Shift + щелчок по диаграмме устанавливает B, не меняя выделение.
Вложенность групп и битов показана отступами и направляющими слева.
Правая кнопка на выделенной строке сохраняет выделение. Radix и Signal Color
применяются ко всему набору; New Group объединяет выбранные сигналы. Для изменения
одной строки щёлкните по ней без модификаторов и затем откройте её меню.

Щелчок по стрелке `>` раскрывает шину или группу, повторный — сворачивает.
Побитные индексы подготавливаются при первом раскрытии в фоне; операция отменяется
кнопкой «Отмена». Для каждого бита доступны собственные цвет, Radix, поиск и
переходы по **его** изменениям. Остальные биты не создают ложных фронтов.
Повторное раскрытие использует уже подготовленные индексы.
Фильтр по имени не меняет состояние раскрытия: свёрнутую шину можно оставить
свёрнутой при фильтрации, и очистка фильтра не раскроет её заново.

Правая кнопка по строке открывает меню:

- **Radix** — формат выделенных сигналов; Default наследует общий Radix.
- **Signal Color** — цвет выделенных строк. «По теме / наследовать…» возвращает цвет темы
  либо цвет родительской шины/группы. Явно заданный цвет сохраняется при смене темы.
  «Подходит» означает контраст не менее 3:1 к обычному и выделенному фону, а также
  цветовое отличие от других видимых сигналов. Поэтому похожий фиолетовый
  не предлагается рядом с синим сигналом. Это не заменяет проверку доступности
  интерфейса для конкретного пользователя.
- **Reverse Bit Order** — переворот отображаемого значения шины и диапазона в имени.
  Порядок раскрытых битов остаётся прежним, исходные данные не изменяются.
  Поиск учитывает перевёрнутое представление. Это соответствует
  [описанию команды в Vivado](https://docs.amd.com/r/en-US/ug900-vivado-logic-simulation/Reversing-the-Bus-Bit-Order).
- **Find Value** — переводит фокус в строку поиска для выбранного сигнала.
- **New Divider** — вставляет именованный разделитель после выбранной строки.
- **New Group** — создаёт группу и помещает в неё выбранные сигналы или группы.
  На выбранном бите создаётся пустая группа верхнего уровня.
- **Go to Source Code** — пока отключено. В коде есть интерфейс для подключения
  поиска исходного HDL; ложные пути к исходникам не создаются.

Группы и разделители можно переименовать через то же меню. Удаление группы
убирает из просмотра группу и всё её содержимое, включая вложенные группы.
CSV и исходные данные захвата не меняются; повторное открытие CSV восстанавливает
первоначальный список. Снизу находится свёрнутая группа
«Параметры захвата» с отдельными значками для Sample in Buffer / Sample in Window:
у них показывается значение в точке A, без отдельной диаграммы.

Расстановка, группы и индивидуальные настройки сигналов действуют в текущем
открытом захвате; сохраняются только общие настройки приложения.

## Управление

Чтобы использовать навигационные клавиши, щёлкните по диаграмме.
В поле ввода стрелки редактируют текст как обычно.

| Действие | Управление |
|---|---|
| Выбрать сигнал, поставить A | Щелчок по строке диаграммы |
| Добавить / убрать сигнал из выделения, поставить A | Ctrl + щелчок по строке диаграммы |
| Выбрать все видимые сигналы | Ctrl+A после щелчка в Name/Value |
| Выбрать весь диапазон отсчётов | Ctrl+A после щелчка по диаграмме: A=начало, B=граница после последнего отсчёта |
| Выделить диапазон строк | Shift + щелчок в Name или Value |
| Поставить B | Shift + щелчок по диаграмме |
| Переместить курсор | Удерживать левую кнопку на линии маркера; для B — Shift |
| Приблизить участок диаграммы | Протянуть ЛКМ от одного края участка к другому |
| Убрать B | Обычный левый щелчок по диаграмме; также Esc или меню «Настройки» |
| Предыдущее / следующее изменение | ← / →; при отсутствии изменения — начало / конец захвата |
| A на один отсчёт назад / вперёд | Ctrl + ← / → |
| Выбрать соседний сигнал | ↑ / ↓ |
| Прокрутить сигналы | Колесо или вертикальная полоса |
| Прокрутить время | Shift + колесо, Shift + ← / →, средняя кнопка + движение |
| Масштаб под мышью | Ctrl + колесо |
| Масштаб относительно A, если он виден | + / − |
| Уместить весь захват | F или «Весь захват» |
| Приблизить между курсорами | «A ↔ B» |
| Начало / конец | Home / End |
| Перейти к отсчёту | Ctrl+G |
| Найти значение | Ctrl+F, ввести значение, Enter |
| Следующее / предыдущее совпадение | F3 / Shift+F3 |
| Изменить общий формат | Настройки → Настройки… → Вид → Общий Radix |
| Изменить формат выделения | Правая кнопка → Radix |
| Подобрать ширину Name / Value | Двойной щелчок по правой границе колонки |
| Полное имя и значение без сокращения | Навести мышь на сигнал |
| Справка | F1 |

При наведении на видимый маркер A/B указатель становится горизонтальной стрелкой
перемещения. Для перемещения B удерживайте Shift; обычный щелчок по диаграмме
убирает B и ставит A, в том числе при нажатии на линию B.
Положение при щелчке округляется к **ближайшему** отсчёту, в том числе если
указатель оказался чуть левее его линии.

### Приближение протягиванием мыши

Нажмите ЛКМ на диаграмме **вне линии маркера**, протяните мышь влево или вправо
и отпустите. Полупрозрачная полоса показывает будущий диапазон. Масштаб меняется
только если мышь прошла порог перетаскивания, выбранный диапазон содержит не менее
двух отсчётов и уже текущего вида. Короткий щелчок ставит A; слишком узкий
диапазон не меняет масштаб. Shift+ЛКМ продолжает управлять B. Esc отменяет жест.

### Копирование значений

1. Выделите сигнал, несколько сигналов или нужные раскрытые биты в Name/Value.
2. Установите A и B на границы диапазона либо оставьте B неустановленным, чтобы
   скопировать весь захват. Можно сначала установить маркеры,
   а затем выбрать строки: выделение в Name/Value не меняет маркеры.
3. Нажмите правой кнопкой на сигнале и выберите **Copy Values…**.
   Меню доступно и в списке имён. Правый щелчок по уже
   выделенной строке сохраняет множественный выбор; по другой строке выбирает её.

В окне копирования галочками можно добавить сигналы, не выделенные на диаграмме.
Для каждого выбранного сигнала отдельно выбираются Radix и, для шины,
диапазоны физических битов. Например, `7-1` берёт биты 7…1, а `7-4 2-1` —
два диапазона. Пустое поле означает все биты шины либо уже выделенные биты.
**«Как у сигнала»** использует текущий формат шины. Отображение диаграммы не меняется.
Для нескольких независимых
сигналов создаётся по одной строке на сигнал, в порядке выделенных строк.

Биты одной шины собираются в одно значение в порядке физической значимости:
старший выбранный бит слева. Порядок щелчков и перестановка строк на это не влияют.
Невыбранные биты исключаются; пропуски между битами уплотняются. Для формата по
умолчанию используется Radix родительской шины, не формат отдельных битов.
Если выбраны и шина, и её биты, шина копируется один раз целиком.
Reverse Bit Order родительской шины применяется и к собранному значению.

Например, исходные 9-битные значения `043 1A6 1FF 0EA` при выборе `[7:0]`
копируются как `43 A6 FF EA`; при выборе всех девяти бит — как
`043 1A6 1FF 0EA`. Ширина HEX/BIN/OCT определяется количеством выбранных битов.
Смешанные неизвестные биты X/Z сохраняются, не заменяются нулями.

В окне копирования выбираются:

- Разделитель: пробел, запятая, табуляция, новая строка или без разделителя.
- Галочка «Только уникальные значения»; при её включении доступна сортировка
  по возрастанию или убыванию. Без неё копируются все подходящие отсчёты.

При первом копировании за запуск над диаграммой появится панель настройки периода.
Маркеры A/B на это время скрыты, но их положения сохраняются. Поставьте маркер 1
обычным щелчком, маркер 2 — Shift+щелчком; для перемещения перетаскивайте их
с теми же клавишами. Нажмите **«Подтвердить период»**. Расстояние между точками
задаёт период, первая точка — фазу выборки. Например, точки 5 и 8 дают период 3:
в диапазоне от нулевого отсчёта выборка пойдёт по 2, 5, 8, а не с нуля.
Фаза распространяется и назад от первой точки до начала выбранного диапазона.
Затем откроется немодальный редактор условия с фильтром по именам и галочкой показа полных
имён; добавление сигнала вставляет его имя и пробел в позицию курсора. Кнопка
**«Выбрать период заново»** в редакторе возвращает к панели и сохраняет уже
введённое выражение. Отмена повторной настройки оставляет прежний период.
Пока редактор открыт, можно прокручивать и масштабировать диаграмму.

Значение A включается, отсчёт B служит исключающей границей, независимо от
порядка маркеров. Поэтому значение, начинающееся точно на B, не попадает в копию.
При выборе уникальных значений повторы удаляются в пределах каждого сигнала;
без сортировки сохраняется порядок первого появления. Несколько сигналов
имеют отдельные строки значений.

При каждом запуске Copy Values можно задать условие, например
`tx_ready && tx_we && tx_data == FE`. Список сигналов вставляет имя в позицию
курсора; для составных или неоднозначных имён используется полное имя в обратных
кавычках. Доступны `&&`, `||`, `!`/`~`, сравнения и скобки. Пустое условие не
фильтрует данные. Если диапазон не содержит совпадений, буфер обмена не меняется,
а строка состояния сообщает «Таких данных нет».

Подготовка текста выполняется в фоне с отменой; буфер обмена заменяется только
после успешного завершения. Максимальный результат — 32 млн символов, без
молчаливого обрезания. Для большего результата уменьшите диапазон или выберите
«Только уникальные значения».

### Копирование ячейки и подсветка участков

Правый щелчок в колонке **Name** предлагает **Copy Name**, в колонке **Value** —
**Copy Value**. В буфер попадает именно текст выбранной ячейки, включая её текущий
Radix и точку A для Value; диапазон A…B для этих двух команд не нужен.

Чтобы оставить на диаграмме видимое выделение подходящих участков, поставьте A/B
или оставьте B неустановленным для всего захвата,
щёлкните правой кнопкой и выберите **«Подсветить участки по условию…»**. При первом
использовании потребуется задать тот же период и фазу, что и для Copy Values.
Введите имя группы, выберите один из стилей подсветки и задайте условие,
например `tx_data = F4 && tx_ready && tx_re`. Цвет и прозрачность стилей
настраиваются в общих настройках; при редактировании готовой группы их можно
изменить внизу редактора.
Поддерживаются `=` и `==`, `&&`, `||`, отрицание `!`/`~` и сравнения. Пустое
условие подсветит все периоды. Условие проверяется на отсчётах
`первая_точка + k × период`, включая точки до первой метки, если они попадают
в A…B. Если условие истинно, закрашивается соответствующий отрезок периода;
соседние подходящие отрезки объединяются. B остаётся исключающей границей.

Группы расположены горизонтально под диаграммой **над горизонтальной прокруткой**.
Панель видна и без групп; опция во вкладке «Подсветка» скрывает её, пока групп нет. У каждой есть
галочка видимости, кнопки цвета, редактирования и удаления. Галочка слева от
«+ Подсветка» скрывает или показывает все группы. Обычно повторное включение
восстанавливает прежний набор включённых групп; это можно изменить в настройках.
Редактирование меняет
название, условие, цвет и прозрачность, сохраняя исходный диапазон A/B этой группы. Можно
создать несколько групп; стили задаются во вкладке
**«Настройки → Настройки… → Подсветка»** и сохраняются между запусками. Созданные
группы относятся только к текущему открытому CSV, но сохраняются при его обновлении,
если сигналы в условиях остаются доступными.

### Поиск

Выберите сигнал щелчком по строке, например `port0_rx_data[8:0]`.
В режиме HEX вводите `0AC` или `AC`; в UNSIGNED — `172`.
Префиксы `0xAC` и `0b10101100` явно задают основание независимо от режима.
В SIGNED `-1` для 9-битной шины соответствует битовому шаблону `1FF`.

Результат поиска — **начало интервала**, на котором сигнал равен значению.
Если A уже стоит в начале найденного интервала, повторный Enter переходит
к следующему такому интервалу, а фокус остаётся в поле поиска. Галочка ↻ после
поля включает кольцевой поиск: на краю захвата он продолжится с другого края.
Без галочки поиск остановится на краю. Поиск точный, без масок и регулярных выражений.
X/Z ищутся как точная последовательность символов из CSV, без учёта регистра.

В ASCII можно вводить `AB`, байты `\x00` и `\xFF`; пробелы в начале/конце
заключайте в кавычки. Обратная косая черта экранируется как `\\`.
Signed Magnitude трактует старший бит как знак, остальные — как модуль.
Real поддерживает IEEE 754 для 32/64 бит и Fixed Point с выбранным числом
дробных бит (параметры через Radix → Real Settings). Это числовые подписи
цифровой шины; аналоговый график пока не реализован.

### Отсчёты и время

Ось X — индекс строки данных: `0…N−1`. CSV-столбцы `Sample in Buffer`
и `Sample in Window` показываются внизу для A. Их сброс при следующем
окне захвата не ломает порядок диаграммы.

CSV не задаёт частоту тактирования ILA. В меню **«Настройки → Период отсчёта»**
можно вручную задать период в ns: например, `10` для 100 МГц.
После этого шкала и разность курсоров дополнительно показывают время.
`0` возвращает шкалу отсчётов.

Это время считается как `индекс × период`. Если в ILA использовалось
условное разрешение захвата или между окнами были пропуски, их длительность
из такого CSV восстановить нельзя: соседние сохранённые строки не обязательно
соответствуют соседним тактам.

## Большие файлы

CSV читается последовательно. Для каждого сигнала создаётся индекс
**изменений**, а не набор графических объектов для всех отсчётов.
Массивы индекса хранятся во временной папке и открываются через NumPy memmap;
при закрытии захвата временные файлы удаляются.

Рисуются только видимые строки и участок времени. При очень плотных
переключениях они объединяются в заполненную полосу активности по пикселям,
чтобы краткие импульсы не пропадали при отдалении. Для изучения отдельных
фронтов приблизьте участок. Индекс и поиск сохраняют точные данные.

Ограничения: нужен свободный диск для индекса, а словарь уникальных значений
каждого сигнала хранится в оперативной памяти. Высокоэнтропийные широкие шины,
у которых почти каждый отсчёт уникален, требуют больше памяти. Нет обещания
неограниченного размера: скорость зависит от количества сигналов, уникальных
значений, изменений, диска и процессора. Индекс строится заново при открытии.

Пример замера на этом компьютере: синтетический CSV около 29,8 МБ,
1 000 000 отсчётов, 5 сигналов, включая бит, меняющийся каждый отсчёт.
Загрузка — около 2,3 с, индекс — 28,4 МБ; отрисовка проверенных масштабов
при размере окна 1280×760 — около 1,6–8,1 мс. Построение индексов 9 бит
шины заняло около 0,08 с, полный вид с раскрытой шиной — около 25 мс.
Это внеэкранный тест отрисовки,
не гарантия частоты кадров на другом компьютере.
После запуска benchmark результат записывается в `tests/artifacts/benchmark.json`.
Benchmark также проверяет полмиллиона отдельных совпадающих интервалов подсветки:
на общем виде они уплотняются до количества полос, ограниченного шириной экрана.

## Формат и границы приложения

Ожидается CSV с заголовком и строкой `Radix - ...`, как в экспорте Vivado.
Поддерживаются исходные HEX, BINARY/BIN, OCTAL/OCT, UNSIGNED, SIGNED,
DECIMAL/DEC. Для имени с диапазоном `[msb:lsb]` ширина берётся из имени;
без диапазона ширина определяется по встреченным значениям и может быть
меньше физической ширины сигнала. Для точного SIGNED желательно наличие диапазона.
Ошибки данных сообщаются с номером строки и именем столбца.

Это самостоятельный **офлайн-просмотрщик**, а не полная копия Vivado:
он не управляет FPGA/ILA, не настраивает триггеры захвата и не декодирует
SpaceWire. Симуляция, привязка к HDL и сохранение состояния самого захвата
пока не реализованы; общие настройки вида сохраняются.

## Архитектура

Код разделён на классы и компоненты в `ila_viewer/`; `ila_viewer/__main__.py`
остаётся тонкой точкой запуска. Данные, дерево, оформление, отрисовка и команды
меню разделены. Новые форматы, темы, источники и действия подключаются через
интерфейсы и реестры. Подробности и точки расширения — в
[документе об архитектуре](ARCHITECTURE.md).

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest -v tests.test_waveform tests.test_extensions
.\.venv\Scripts\python.exe -m scripts.benchmark_waveform
```

Тесты проверяют значения искусственного `tests/fixtures/waveform.csv`, поиск в обе стороны,
знаковые и широкие шины, неизвестные состояния, несколько окон захвата,
ошибочные CSV, очистку индекса, отмену, клавиатурную навигацию и крупные
диапазоны прокрутки. Дополнительно проверяются перетаскивание мышью, группы,
раскрытие битов, смена темы, форматы, поведение B, выделение диапазона,
заливка единиц, независимое изменение ширины колонок и загрузка общих настроек.
GUI-тест использует
внеэкранную платформу Qt и сохраняет примеры окна в `tests/artifacts/waveform-reader.png`,
`tests/artifacts/waveform-dark-tree.png`, `tests/artifacts/waveform-light-tree.png` и
`tests/artifacts/waveform-preferences-columns.png`. Тесты используют отдельные хранилища
настроек и не меняют пользовательский `.viewer-settings.json`.

Для интерфейса использованы
[QAbstractScrollArea](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QAbstractScrollArea.html)
и [QThread](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QThread.html).
